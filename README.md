# Emma's Den

Premium marketing website for **Emma's Den** — kids photography studio, children's party venue, and studio rental in Abelemkpe, Accra, Ghana.

> Where Little Moments Become Big Memories.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- `next/image`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
